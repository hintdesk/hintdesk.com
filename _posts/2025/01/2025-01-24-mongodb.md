In this post, I would like to document some useful information about using MongoDB.

## How to connect to MongoDB in Kubernetes

- First you need a port-forwarding
```sh
kubectl port-forward --kubeconfig=your_kube_config.yaml -n your_namespace service/your_mongo_service 27017:27017
```

- In MongoDB Compass, enable the "Direct Connection" option and enter the required authentication details.

{% include image.html year='2025' month='01' file='14_001.png' alt='Direct Connection' %}

To run a script against the database, open the MongoDB shell and run the following:

```sh
db.getMongo().getDBNames().forEach(dbName => {
  // Skip system databases.
  if (["admin", "config", "local", "productsMapping", "hrefLang"].includes(dbName)) return;

  let currentDb = db.getSiblingDB(dbName);
  
  // Check whether the database has a 'content' collection.
  let collections = currentDb.getCollectionNames();
  if (collections.includes("content")) {
    let count = currentDb.content.countDocuments({ "fs_project_name": null });
    if (count > 0) {
      print(`[FOUND] DB: ${dbName} -> Found ${count} matching document(s).`);
      
      // Get the matching documents and print only their pageId values.
      let docs = currentDb.content.find({ "fs_project_name": null }).toArray();
      docs.forEach(doc => {
        // Note: If pageId is nested in channel or another object, update the path accordingly (e.g., doc.channel.pageId).
        print("  - pageId:", doc.pageId);
      });
    }
  }
});
```
